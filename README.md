# SoundCloud Helper

Это локальное Chrome-расширение для SoundCloud.

Что делает:
- добавляет рядом с кнопкой `...` быстрый `＋ Playlist`;
- при нажатии открывает штатное меню SoundCloud;
- находит в нём `Add to Playlist`;
- нажимает штатную кнопку SoundCloud, поэтому выбор плейлиста и авторизация остаются на стороне SoundCloud.

Установка:
1. Распакуйте ZIP.
2. Откройте `chrome://extensions`.
3. Включите `Developer mode`.
4. Нажмите `Load unpacked`.
5. Выберите папку `soundcloud-helper`.
6. Откройте/обновите SoundCloud.

Важно:
Расширение намеренно не использует приватные API SoundCloud и не хранит cookies/пароли. Оно работает через DOM интерфейс сайта. Если SoundCloud изменит HTML-классы или структуру меню, селекторы в `content.js` может потребоваться обновить.
